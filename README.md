Landing Page Responsiva com Bootstrap

Este é um projeto de landing page responsiva desenvolvido com o framework Bootstrap. O objetivo do projeto é criar uma página simples, moderna e responsiva, adaptável a diferentes dispositivos, utilizando os recursos do Bootstrap para facilitar o desenvolvimento.

🚀 Funcionalidades

Navbar Responsiva: Barra de navegação que se adapta automaticamente a telas grandes e pequenas (com menu colapsável).

Hero Section: Uma seção de introdução com título e descrição destacando o projeto.

Seção Sobre: Uma seção explicando o projeto com uma imagem ao lado do texto, em layout responsivo.

Formulário de Contato: Formulário para os usuários entrarem em contato com o administrador, com uma mensagem de sucesso exibida após o envio.

Design Responsivo: O layout da página se ajusta automaticamente a diferentes tamanhos de tela, garantindo uma boa experiência em desktops, tablets e smartphones.

💻 Tecnologias Utilizadas

HTML: Estruturação da página.

CSS: Estilos personalizados para o layout e design.

JavaScript: Interatividade no formulário de contato, incluindo a exibição de mensagens de sucesso.

Bootstrap: Framework CSS utilizado para garantir a responsividade e fornecer componentes prontos, como navbar, botões, e formulários.

🚩 Como Rodar

Clone este repositório:

git clone https://github.com/SEU-USUARIO/landing-page-bootstrap.git


Navegue até a pasta do projeto:

cd landing-page-bootstrap


Abra o arquivo index.html em um navegador:

Você pode abrir o arquivo diretamente no navegador ou, se preferir, usar um servidor local.

Personalize o conteúdo:

Se você quiser fazer alterações ou personalizar o conteúdo, edite os arquivos index.html, style.css e script.js.

📂 Estrutura de Arquivos
landing-page-bootstrap/
│
├── index.html         # Arquivo principal da página
├── style.css          # Estilos personalizados para o projeto
├── script.js          # Interatividade e funcionalidades JavaScript

🎨 Personalização

Hero Section: Alterando o conteúdo da tag <h1> e <p>, você pode mudar a descrição do projeto para algo que melhor se encaixe com o seu caso de uso.

Formulário de Contato: O formulário coleta nome, email e mensagem. Para conectar o formulário a um backend ou serviço de email, basta modificar a ação de envio no form para seu backend.

Estilos: No arquivo style.css, você pode personalizar o design da página, como cores, fontes e espaçamentos.

⚙️ Como Funciona

Navbar: Usamos o sistema de grid do Bootstrap e as classes navbar e navbar-expand-lg para criar uma navegação responsiva, que se adapta a diferentes dispositivos.

Hero Section: Aplicamos classes como bg-info, text-center, e py-5 para garantir que o conteúdo da seção se apresente de maneira clara e com bom espaçamento.

Seção Sobre: Utilizamos o grid do Bootstrap com as classes col-md-6 e img-fluid para tornar a seção responsiva e garantir que a imagem se ajuste bem na tela.

Formulário: Usamos as classes form-control, btn-primary, e btn-block do Bootstrap para estilizar os campos de entrada e o botão do formulário de forma simples e eficiente.
